Capabilities

Everything you need to govern AI agents

One library. Every framework. Full control over what your agents can do.

⚙

Policy Engine

YAML-based rules that allow, score, or block actions by pattern. Hot-reload policies without restarting.

⚠

Risk Scoring

Every tool call gets a 0-100 risk score. Configurable thresholds determine allow, intervene, or block.

🔍

Anomaly Detection

Catches loops, drift, hallucinations, and contradictions before they cause damage.

⚡

Circuit Breaker

Automatically trips when error rates spike. Protects downstream systems from runaway agents.

👥

Human-in-the-Loop

Medium-risk actions pause for approval. Configurable callbacks, webhooks, or dashboard-based review.

📈

Full Observability

Every evaluation is traced and stored. Web dashboard, metrics, real-time WebSocket streaming.

Quick Start

Five lines to safety

Drop Ostiari into any agent in minutes. No framework lock-in.

main.py 
from ostiari import Guard
from ostiari.models import OstiariConfig, ThresholdConfig

# Configure: allow <= 30, intervene 31-70, block > 70
config = OstiariConfig(
    thresholds=ThresholdConfig(allow_max=30, intervene_max=70),
    fail_open=False,
)

guard = Guard(config=config)
guard.configure("policy.yaml")
guard.start()

# Validate before executing any tool call
result = guard.validate(
    action="email.send",
    params={"to": "user@example.com", "subject": "Hello"}
)

if result.tier == "allow":
    send_email(result.params)  # Low risk — proceed
elif result.tier == "intervene":
    if get_human_approval(result):
        send_email(result.params)  # Approved

Decision Tiers

Three outcomes, zero ambiguity

Every action maps to a clear decision. No guesswork.

0-30
Allow

Low risk. Action proceeds immediately with no intervention. Read operations, safe searches, permitted queries.

31-70
Intervene

Medium risk. Pauses for human approval. Sends email, writes files, external API calls with side effects.

71-100
Block

High risk. Action rejected immediately. Deletes, code execution, system commands, privilege escalation.
