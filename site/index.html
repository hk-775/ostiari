Ostiari

Runtime governance for AI agents: authorize, quota, score, approve, pay, execute, and trace HTTP, MCP, A2A, and LLM traffic from one control plane.

Agent / SDK                  Ostiari gateway                       Governed target

  POST /tool/{action}  ----->  1. Delegation  (A2A edge / trust / depth)
                              2. Authorization (agent grants)
                              3. Quota        (rate / tokens / budget)
                              4. Risk         (allow / intervene / block)
                              5. Approval     (optional HITL, HTTP 202)
                              6. Payment      (metered or x402)
                              7. Execute      -----------------------> HTTP / MCP / A2A / LLM
                              8. Trace        -----------------------> Control plane

Capabilities

Everything you need to govern AI agents

A gateway enforcement path, an embeddable Guard, and a fleet control plane.

⚙

Complete gate chain

Delegation, authorization, quota, risk, approval, payment, execution, and durable trace delivery.

⚠

Universal tool proxy

Govern HTTP tools, real stdio or remote MCP servers, peer agents, and LLM provider traffic.

🔍

Human approval

Intervene-tier gateway calls pause with HTTP 202 and execute only after an approved retry.

⚡

Fleet control plane

Push policy and quotas, manage approvals, monitor health, and inspect linked traces and audit evidence.

👥

Metering and payments

Track model and tool cost, enforce agent budgets, and support metered or downstream x402 settlement.

📈

Deployment profiles

Run locally, evaluate on AWS, add an AgentCore validation bridge, or prepare a reviewed production change set.

Quick Start

Embed the Guard directly

Use the in-process decision engine when your application owns execution and does not need the gateway or control plane.

main.py 
from ostiari import ActionBlockedError, Guard
from ostiari.models import OstiariConfig, ThresholdConfig

# Configure: allow <= 30, intervene 31-70, block > 70
config = OstiariConfig(
    thresholds=ThresholdConfig(allow_max=30, intervene_max=70),
    fail_open=False,
)

guard = Guard(config=config)
guard.configure("policy.yaml")
guard.start()

try:
    result = guard.validate(
        action="email.send",
        params={"to": "user@example.com"}
    )
    if result.original_tier == "intervene":
        if get_human_approval(result):
            send_email(result.params)
    elif result.tier == "allow":
        send_email(result.params)
except ActionBlockedError:
    record_refusal()

Decision Tiers

Three outcomes, zero ambiguity

Every action maps to a clear decision. No guesswork.

0-30
Allow

Low risk. Action proceeds immediately with no intervention. Read operations, safe searches, permitted queries.

31-70
Intervene

Medium risk. The gateway can pause asynchronously for approval; the embedded Guard resolves the tier synchronously.

71-100
Block

High risk. Action rejected immediately. Deletes, code execution, system commands, privilege escalation.
