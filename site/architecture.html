Request Flow

Every agent tool call passes through the Ostiari pipeline before reaching the outside world.

  1. Agent invokes a tool — any framework (OpenAI, Strands, Anthropic, Bedrock, CrewAI, LangGraph, AgentCore)
  2. Ostiari intercepts via the framework adapter or Agent Harness middleware
  3. Policy Engine evaluates — matches YAML rules, applies risk adjustments
  4. Anomaly Detector checks — loops, drift, hallucination, contradiction
  5. Gateway scores — combines signals into a 0-100 risk score and assigns a tier
  6. Decision: Allow / Intervene / Block — tier determines outcome
  7. Trace stored — full evaluation result persisted for observability

AWS Services

Amazon CloudFront

Global CDN serving the landing page and dashboard static assets. Routes /api/* requests to API Gateway origin.

Amazon S3

Stores the landing page HTML, dashboard UI, and architecture diagrams. Private bucket accessible only via CloudFront OAI.

API Gateway (HTTP API)

Serverless HTTP endpoint fronting the Lambda function. Handles /api/traces, /api/policy, /api/harness, /api/registry routes.

AWS Lambda

Runs the FastAPI dashboard backend via Mangum adapter. Handles trace queries, policy CRUD, harness invocations, and registry operations.

Amazon Bedrock

Provides LLM inference via the Converse API. All 7 agents use Bedrock models (configurable model ID via environment variable).

Bedrock AgentCore

Agent Registry for semantic search across registered agents. Stores agent metadata, tools, risk profiles, and policy associations.

Ostiari Core Components

Policy Engine

Evaluates YAML-based rules with pattern matching, wildcards, and risk adjustments. Supports hot-reload via polling.

Anomaly Detector

Four detectors: loop detection (repeated actions), drift (deviation from patterns), hallucination (non-existent resources), contradiction (conflicting actions).

Gateway (Risk Scorer)

Combines policy score + anomaly signals into a final 0-100 risk score. Maps to tier: allow (0-30), intervene (31-70), block (71-100).

Circuit Breaker

Trips when error/block rates exceed thresholds. States: closed (normal) → open (all blocked) → half-open (test calls).

Agent Harness

Managed runtime wrapping agents with session management, rate limiting, memory, and guardrail middleware on the tool invocation path.

Trace Storage

Records every evaluation: action, params, score, tier, anomalies, latency. SQLite locally, DynamoDB in production. Includes redaction filter.
